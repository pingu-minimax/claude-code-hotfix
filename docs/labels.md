# Label Organization Guide

## Introduction

Proper label organization is crucial for maintaining a clean and understandable codebase. This guide provides conventions and examples to ensure consistent and effective label usage.

## Conventions

1. **Format**: Labels should be in lowercase and use hyphens to separate words.
2. **Prefixes**: Use prefixes to categorize labels, e.g., `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`.
3. **Descriptive**: Labels should be descriptive and concise.
4. **No Commas**: Avoid using commas in labels.

## Examples

- `feat(user-auth): add login functionality`
- `fix(api): resolve authentication endpoint issue`
- `docs(readme): update installation instructions`
- `style(css): adjust button padding`
- `refactor(api): consolidate user endpoints`
- `test(unit): add login test cases`
- `chore(deps): update dependencies`
